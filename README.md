# Futuristic Portfolio Website

A responsive portfolio starter made with plain HTML, CSS, and JavaScript. Ready for GitHub Pages.

## Customize before publishing

1. Open `index.html`.
2. Replace every `YOUR NAME` / `Your Name` with your preferred display name.
3. Update the About paragraph to describe yourself.
4. Edit the Skills cards to match skills you actually have.
5. Replace the sample Projects with your real projects and descriptions.
6. Replace `you@example.com`, `yourusername`, and the LinkedIn placeholder with your own links.
7. Update the page title and description in the `<head>` section.

## Preview locally

Open `index.html` in a browser. No build tools or installation are required.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `my-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages settings.

Tip: Keep the filenames exactly as shown and make sure `index.html` is in the repository root.
